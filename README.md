# EBC2014
Datasets for course project

The datasets in this repository have been created for use by students in their team project on international trade and trade policies. The data sets have been compiled using various official sources of national and international statistics. However they are presented in a fashion that is easy to use, so that the full set up process is not documented here. Accordingly, the data does not claim to exactly reflect any official statistical figures and should, hence, not be used or referred to in any context outside the course and project. 


# Dataset for US Elections project

The dataset is available in csv-format and can be imported directly into statistical packages like R or Stata, using the file URL. The dataset consists of 17 columns and 122,480 rows. Columns are defined as follows:

state "US State"

state_po "US State (abbreviation)"

county_fips "County code (ID)"

country_name "County name"

ind "NAICS Industry Code"

description "NAICS Industry Description"

year "Year (only relevant for GOP share)"

X "Total US industry exports (2017)"

X_China "US industry exports to China (2017)"

M "Total US industry imports (2017)"

M_China "US industry imports from China (2017)"

Xtariff "Average industry tariff faced in China (2017)"

Mtariff "Average industry tariff imposed on China (2017)"

L "Local industry employment (2016)"

Lshare_US "Local industry employment as share of US total industry employment (2016)"

Lshare_cty "Local industry employment as share of total local employment (2016)"

GOPshare "County-level GOP share in US Presidential elections"
