# EBC2014
Datasets for course project

The datasets in this repository have been created for use by students in their team project on international trade and trade policies. The data sets have been compiled using various official sources of national and international statistics. However they are presented in a fashion that is easy to use, so that the full set up process is not documented here. Accordingly, the data does not claim to exactly reflect any official statistical figures and should, hence, not be used or referred to in any context outside the course and project. 

# Dataset for CBAM project

The dataset is available in csv-format and can be imported directly into statistical packages like R or Stata, using the file URL. The consists of 12 columns and 3,097 rows. Columns are defined as follows:

iso3_exp "Exporter ISO3 code"

exporter "Exporter name" 

GEO "Exporter region"

nGDP "Exporter's GDP (2016), million US dollars"

rank "Exporter rank (value of exports, excl. EU27 and EFTA)"

share "Exporter's share in world exports"

sector "NACE rev. 1 sector name"

NACEr1 "NACE rev. 1 sector code"

CO2_intensity "Relative CO2 intensity of NACE rev. 1 sector"

destination "Destination of Exports"

X "Value of exports to destination (2016), thousand USD"

X_CBAM  "Value of CBAM exports to destination (2016), thousand USD"
